# PickWeight 点名提醒

接收 PickWeight 的抽取结果，并在 ClassIsland 主界面的遮罩和正文显示“XXX被抽中”提醒。

## 提醒设置

在 ClassIsland 的提醒设置中找到“PickWeight 点名结果”，可以配置：

- 遮罩和正文显示时长
- 是否显示正文
- 遮罩和正文是否播报抽中名单
- ClassIsland 提供的提醒总开关、音效、特效和置顶设置

## 使用方法

1. 安装并启用本插件。
2. 启动 PickWeight，并在设置中开启“ClassIsland 抽取提醒”。
3. 在 PickWeight 中开始抽取。

ClassIsland 未运行或插件未启用时，PickWeight 的正常抽取不会受到影响。
